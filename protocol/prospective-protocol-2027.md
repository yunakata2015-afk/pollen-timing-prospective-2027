## 1. 目的と位置づけ

- 開始日・本格飛散開始日が「7日以内／3日以内」に到来する確率を、式を凍結した上で全国規模で前向きに検証する。
- **位置づけは「確認の層」であって主証拠ではない。** 主証拠は多年の後ろ向き検証（訓練2007–2021 → 時間テスト2024–2026、環境省ダーラム法65地点年）のまま。1シーズンのサンプルは小さく、順位は偶然で入れ替わり得る。
- 前向きの価値は「どっちが勝つか」より「凍結した予測が、後ろ向きで見た通りの較正を保つか」の確認にある。

- **原則（2026-11-19決定）：観測可能な地点でのみ行う。** 2027年に環境省実測調査（ダーラム法）等の観測が継続し、シーズン後にラベルが取得可能な地点だけを対象とする。観測が終了した地点は、理由を記録した上で対象から外す。固定の地点リストで縛らない。

- **地点の増減への対応**：対象地点の名簿（地点名・都道府県・気象庁エリアコード・対応はなこさん地点・状態）は一覧ファイルで管理し、予報収集と確率計算のスクリプトは名簿を読んで動く（地点をスクリプトに固定しない）。名簿の変更は上記の原則に基づく**運用**として日時と理由を記録するものであり、凍結した式・プール・較正の変更には当たらない（各地点の確率は、その地点の中心と凍結済みの偏差分布だけで決まるため、名簿の増減は他の地点の予測に影響しない）。シーズン途中で観測が終了した地点は、その日までの予測をアーカイブに残し、評価の対象からのみ外す。新規の地点はフォールバック（対応地点 → 県平均 → ブロック平均）でそのまま予測対象にできる。
- **予報点**：基本的には都道府県の代表点（気象観測地点）の予報を使う。対象地点の市区町村とずれていても、その県を代表する気象予報として扱う（本人の方針、2026-11-19）。訓練側の気象も県代表地点で統一されているため、実測と予報で代表点の原則は揃っている。週間予報の気温点は県内に1–2点しかないため、使う点を名簿に記録しておく（例：山口県は下関のみ、埼玉県は熊谷のみ）。収集は県単位でファイルごと取るため、点単位の取りこぼしは生じない。残る失敗は取得自体の失敗のみで、その場合は §5 の通り報告する。

## 3. 凍結モデル（主解析）

主役は2モデル。RFとアンサンブルは主役にしない。

### 3.1 気候値（Climatology）

- 確率は、プールした偏差分布の経験CDFから計算する。偏差 = 学習年のイベント日（年間日 DOY）− 地点中心。予測日 d について：

```
P_clim(d) = F_doy( DOY(d+k) − 中心 ) − F_doy( DOY(d) − 中心 )   （k = 7 または 3）
```

- 中心は原則として対応するはなこさん地点の2007–2021年履歴の平均。対応がない場合は県平均 → ブロック平均の順にフォールバックする。偏差分布のプール先は §3.3 の構造に従う。
- 予報は一切使わない。

### 3.2 積算気温ルール（確率化）

- 積算気温：当年1月1日起算の日平均気温の累積和。日平均気温は（最高＋最低）÷2。気象は県代表地点（気象台）の日次データを用いる。
- 閾値 θ の中心は、対応するはなこさん地点の2007–2021年履歴における「イベント日の積算気温」の平均。フォールバックは気候値と同順。
- 確率は、プールした偏差分布の経験CDFから計算する。偏差 = 学習年のイベント日の積算気温 − 中心 θ。予測日 d について：

```
P_rule(d) = F_th( 積算気温(d+k) − 中心θ ) − F_th( 積算気温(d) − 中心θ )
```

- 到達日 ê（当年シーズン内で積算気温が初めて中心 θ に達する日）は、この確率が立ち上がる位置を与える（前向きの投影方法は §5）。

### 3.3 プール構造

- **主構造 = B（太平洋プール設計）**：太平洋側気候＋瀬戸内海気候の地点は太平洋プールの偏差分布、それ以外の地点は自ブロックの偏差分布を使う。気候区分の判定は気象庁の気候区分による（山梨県＝太平洋側、長野県＝日本海側、彦根・長浜・米原・高島は日本海側、福井は県一括で日本海側）。
- **比較構造 = A（ブロックプール）**：事前指定の比較として併記し、2027年もA・B両方の確率をアーカイブする。

### 3.4 訓練データと欠測

- 訓練：はなこさん 2007–2021年（1,561地点年）。地点の中心は当該地点の履歴が3年以上ある場合に作る。
- **欠測除外**：2–4月のカバー率が0.80未満の地点年を訓練から除外する（46地点年、除外後は1,515地点年）。
- 欠測は欠測のまま扱い、ゼロ補完はしない。

### 3.5 較正（Platt、凍結済みパラメータ）

- 訓練期間の年単位交差検証（leave-one-year-out）予測にロジスティック較正を当てたマップをそのまま使う。前向きでは再調整しない。
- 式：p_cal = sigmoid(a + b · logit(p_raw))、p_raw は 0.001–0.999 にクリップ。

| モデル | 開始7日 | 開始3日 | 本格7日 | 本格3日 |
|---|---|---|---|---|
| 気候値 | a=+0.018, b=0.197 | a=−0.622, b=0.313 | a=+0.372, b=0.721 | a=+0.108, b=0.724 |
| ルール | a=+0.321, b=0.327 | a=−0.565, b=0.299 | a=+0.578, b=0.815 | a=+0.440, b=0.837 |

- 出力（主解析）：開始7日・開始3日・本格7日・本格3日の4つの確率 × 2モデル × 構造A・B。

## 4. 副次モデル（分岐版、2026-11-19決定：事前登録する）

- 固定 θ の主モデルは差し替えず、分岐版を副次モデルとして併走アーカイブする。主解析の結論には使わない。
- 方式：θ の中心を、そのシーズンの**12–1月の平均気温の平年偏差** ΔDJ（°C、県代表地点）で連続的にシフトさせる：
  - 開始：θ' = θ + 19.8 × ΔDJ
  - 本格：θ' = θ + 11.7 × ΔDJ
- ΔDJ は評価開始（2月1日）の時点で確定する。較正は主モデルのルール用マップをそのまま適用する（バックテストと同じ扱い）。
- 根拠（バックテスト、2024–2026・太平洋58地点年）：全体Brier 現行 0.1391 → 12–1月版 0.1249。留保：テスト3年のみ、較正は未 refit。

## 5. 前向き化の方法（ê の投影と予報フィード）

- 昨日まで：気象観測の実測の日平均気温で積算する。
- 今日から先：気象庁の週間予報の日別最高・最低気温で積算曲線を投影し、投影上の到達日 ê を出す。日平均 ≒（最高＋最低）÷2 で近似する。
- **予報フィード（2026-11-19決定）**：気象庁 https://www.jma.go.jp/bosai/forecast/ の **11時公表**の予報を、毎日 **13時に収集**し、スプレッドシートに出力する。**取得できなかった場合は、その日のうちに本人へ報告する**（無言で欠落させない）。
- 予報誤差が乗る分、後ろ向きの数字より少し不利になるのが普通で、それごと測るのが前向き検証の意味である。

## 6. ラベル（結果はあとで収集する）

- ラベル源はダーラム法に揃える。主：環境省実測調査。アンカー：滋賀医大ダーラム（大津）。
- ラベル定義は後ろ向きと完全に同一：季節合計（2月1日–5月31日の日別花粉量の総和）に対し、開始日＝累積2.5%到達日、本格飛散開始日＝累積10%到達日。
- 評価の条件を後ろ向きテストと揃えるため、収集したダーラムの開始日・本格日には方法間オフセット補正（開始 **−9日**・本格 **−1日**、大津の並行期間2007–2021年・n=15の中央値）を適用したものを主解析とし、未補正を感度解析とする。予測の計算自体はラベルを一切使わないため、この補正はシーズン後の評価時にのみ入る。
- 公表ラグがあるため最終評価は2027年後半になる。前向き性は「予測を結果より先に凍結・保存した」ことで担保される。

## 7. 日次手順と保存

- 期間：**2027年1月1日から蓄積・計算を開始**し、4月30日まで。評価窓は2月1日–4月30日。
- 毎日の手順：13時に予報を収集 → 実測で積算を更新し ê を投影 → 主解析（気候値・ルール、構造A・B）＋副次（分岐版）＋大津アンカーの日次確率を計算 → 日付と一緒に追記専用で保存する。
- **保存先（2026-11-19決定）：本人の Google Drive**（スプレッドシート）。予報の収集結果も同じ Drive のスプレッドシートに出力する。
- 報告ルール：保存は無言で回す。報告は「いずれかの地点の確率が50%・80%を超えた日」と週1回のまとめ、および予報が取得できなかった日の報告に限る。
- 1月と4月の端境期は2日に1回に落としてよい（確率はその時期ほとんど動かない）。

## 8. 評価（シーズン終了後）

- 観測された開始日・本格日と、保存した確率列を Brier スコアで突き合わせる。主解析は対象全地点を束ねたプール評価（構造B、較正後）。構造Aは事前指定の比較として併記する。
- 大津アンカーは個別に評価する（プールには混ぜない）。
- 分岐版は副次評価として、主モデル（固定θ）との差を報告する。
- シナリオ：
  - 良い場合：開始で積算ルールが気候値に勝ち、較正も保たれる → 「前向き検証で確認された」という論文の一番強い節になる。
  - 中間の場合（一番ありそう）：2モデルが互角で、どちらも概ね較正されている → 「単純な確率化ルールは前向きでも気候値と同等に使える」。今の論文の正直な主張と一致し、これでも十分書ける。
  - 悪い場合：記録的な暖冬などで開始が平年より大幅に早まり、両モデルとも外す → 気候値は「平年からずれた年にこそ外れる」ことが前向きに示せて、気象を使う積算ルールの存在理由の裏付けになる。
- **結果の良し悪しにかかわらず報告する。** 受け皿は英文誌（論文2）に加え和文誌も可とする。
