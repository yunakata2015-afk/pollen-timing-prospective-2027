# Daily predictions

Daily forecast files for the 2027 season will be pushed here from
2027-01-01 to 2027-04-30 (append-only).

Each day's record gives, per site and per model (climatology /
cumulative-temperature rule, primary structure B and comparator structure A,
plus the pre-registered branch variant and the Otsu anchor), the calibrated
probabilities that dispersal onset / full onset occurs within 7 days and
within 3 days. Probabilities are computed only from data available that day:
observed temperatures up to yesterday, extended with the JMA 7-day forecast
issued at 11:00 JST and collected at 13:00 JST.
